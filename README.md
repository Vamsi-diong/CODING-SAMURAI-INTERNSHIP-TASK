# Coding Samurai Data Science Internship

This repository contains projects completed as part of the Coding Samurai Data Science Internship.

## Project 1: Sales Data Analysis

### Overview
A beginner-level Data Science project that analyzes simulated retail sales data using Python.

### Objectives
- Explore and clean sales data.
- Handle missing values and duplicate records.
- Calculate key sales metrics.
- Identify top-performing products and categories.
- Analyze monthly sales trends.
- Create charts to communicate findings.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

### Key Findings
- Total simulated revenue: ₹51,16,360
- Total orders: 200
- Total units sold: 597
- Highest-revenue product: Laptop
- Highest-revenue category: Electronics
- Highest unit sales by product: Notebook

### Project File
- `Sales_Data_Analysis.ipynb` — includes the Python code, data cleaning, analysis, visualizations, and conclusions.

### Dataset Note
The sales dataset is generated programmatically for educational purposes. It does not represent real business transactions.
