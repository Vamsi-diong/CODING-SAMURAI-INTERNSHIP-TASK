# Coding Samurai Data Science Internship

This repository contains two data science projects completed as part of the Coding Samurai Data Science Internship. The projects demonstrate practical skills in data cleaning, exploratory data analysis, statistical summaries, and data visualization using Python.

## Projects

### Project 1: Sales Data Analysis

**Level:** Beginner

**Objective:** Analyze simulated retail sales data to understand product performance, category revenue, and monthly sales trends.

**Key Activities**
- Generated a sample retail sales dataset using Python, NumPy, and Pandas.
- Inspected the dataset structure and data types.
- Identified and handled missing values and duplicate records.
- Calculated total revenue, order count, units sold, and average order value.
- Compared product and category performance.
- Created visualizations for product revenue, category revenue share, and monthly sales trends.
- Documented key findings and conclusions.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Google Colab.

**Notebook:** [Sales_Data_Analysis.ipynb](./Sales_Data_Analysis.ipynb)

**Dataset note:** The sales dataset was generated programmatically for educational purposes. It does not represent actual business transactions.

### Project 2: Titanic Dataset — Exploratory Data Analysis (EDA)

**Level:** Intermediate

**Objective:** Explore the Titanic passenger dataset to investigate survival patterns, missing values, and relationships between passenger characteristics.

**Key Activities**
- Loaded and inspected the Titanic teaching dataset.
- Examined dataset columns, data types, descriptive statistics, and missing values.
- Analyzed overall survival counts and survival rates.
- Compared survival rates by gender and passenger class.
- Explored passenger age distributions and age-related survival patterns.
- Handled missing age and embarkation values using appropriate filling strategies.
- Created visualizations, including bar charts, histograms, and a correlation heatmap.
- Documented key findings and conclusions.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab.

**Notebook:** [Titanic_EDA.ipynb](./Titanic_EDA.ipynb)

**Dataset note:** This project uses the Titanic teaching dataset provided through Seaborn for educational analysis.
